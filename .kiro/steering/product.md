# Product Overview

Datti は割り勘・立て替えを管理する Web アプリ。「誰がいくら払ったか」を記録・共有し、グループ内の精算（誰が誰にいくら返すか）を簡単にする。

## Core Capabilities

- **立て替え記録 (Lending)**: 1 回の支払いに対し、複数メンバーへの債務 (Debt) を割り当てて記録する
- **グループ精算 (Group)**: グループ単位でメンバーを管理し、グループ内の貸し借りを集計する
- **返済管理 (Repayment / Credit)**: 個人間の貸借残高を可視化し、返済の記録を残す
- **ユーザープロフィール**: アバター画像のアップロード (R2 / 署名付き URL) を含むユーザー管理
- **ソーシャルログイン**: Google / LINE フェデレーション認証 (Cognito 経由)

## Target Use Cases

- 旅行・飲み会・同居など、複数人で発生した立て替えを後から精算したいケース
- グループメンバー間で「誰が誰にいくら返すべきか」を一目で把握したいケース

## Value Proposition

- 立て替えの「記録」から「精算」までを 1 つのサービスで完結
- ソーシャルログインで導入障壁が低く、モバイル / PC 双方で使えるレスポンシブ UI
- 通貨はすべて円 (整数) で扱い、端数や為替の曖昧さを排除

## Domain Vocabulary

| 用語 | 意味 |
|------|------|
| Lending | 立て替え（誰かが支払った 1 件のイベント） |
| Debt | Lending 内の個別債務（誰がいくら負担するか） |
| Repayment | 返済の記録 |
| Credit | 個人間の貸借残高 |
| Group | 精算の単位となるメンバーの集まり |
